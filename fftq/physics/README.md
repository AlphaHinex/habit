```
一、音调：声音的高低
1. 跟物体振动的频率有关，物体振动的快，发出的音调就高；振动的慢，音调就低；频率决定音调。
2. 频率：
① 物理意义：表示物体振动的快慢的物理量。
② 物体每秒内振动的次数叫频率。
③ 符号：f
④ 单位：赫兹（Hz）
⑤ 人耳听觉范围：20Hz-20000Hz。
⑥ 超声波：高于20000Hz的声。（蝙蝠、海豚可发出）特点：穿透性强
次声波：低于20Hz的声。（地震、海啸、台风、火山喷发）大象等动物可听到。
3：解释现象：
①：采了蜜的蜜蜂音调变低。
②：弦乐器：琴弦越松、粗、长，音调越低；（音调）
用力弹不会改变琴弦的音调
③：打击乐器：鼓面越大、厚，音调越低；
④：管乐器空气柱越长，音调越低；
⑤：向水瓶中灌水是空气柱在振动，越灌，空气柱越短，音调越高。
吹瓶子：音调变高（左→右）。空气柱在震
敲瓶子：音调变低（左→右），瓶和水在震。

二、响度：声音的大小（强弱）叫响度。
1. 响度跟振幅有关；振幅越大，响度越大。
还与距离发声体的远近有关；距离越近，响度越大。
2. ①：轻敲，响度小；乒乓球弹开幅度小。
②：运用转换法方法。
3. 解释现象：
①：震耳欲聋形容响度大；
②：引吭高歌形容响度大；
③：低声细语形容响度小；
④：牛比鸟声音的响度大，鸟比牛的音调高；
⑤：男低音唱歌，女高音伴唱，男低音响度比女高音大，女高音音调比男低音高。

三、音色：声音的品质（音品）。
1. 音色和发声体的材料、结构有关。
2. 解释现象：
①：能区分交响乐乐器是因为音色不同；
②：能区分每个人说话不同是因为音色不同。
```

噪声的危害和控制
一、定义
① 物理学：噪声是物体做无规则振动发出的声音。
② 从环保角度看，凡是妨碍人们正常工作、学习和休息的声音，以及对人要听到的声音产生干扰作用的声音，都属于噪声。

二、噪声强弱的等级和危害
1. 单位：分贝（dB）
2. ① 0 dB是人耳能听到的最微弱的声音；
② 30 - 50 dB是较理想的安静环境。
③ 为了保护听力，声音不得超过90 dB；
④ 为了保证工作和学习，声音不得超过70 dB；
⑤ 为了保证休息和睡眠，声音不得超过50 dB。

三、控制噪声
防止噪声的产生；阻断噪声的传播；防止噪声进入人耳。
即：
1. 在声源处减弱噪声；例如：消声器
2. 在传播过程中减弱噪声；例如：关门窗、隔音板、植树
3. 在人耳处减弱噪声。例如：捂耳朵、带耳塞

温度
一、温度定义：表示物体的冷热程度，凭感觉判断温度不准

二、温度计：测量温度的工具。
①原理：常用温度计是根据液体的热胀冷缩的性质制成的。
液体包括：水银、煤油、酒精。
按用途分：实验室用温度计、寒暑表、体温计。

摄氏温度：温度计上的字母℃表示的是摄氏温度。
摄氏温度的规定：在一个标准大气压下冰水混合物的温度是0摄氏度，沸水的温度是100摄氏度，0℃和100℃之间分成100等份，每等份代表1℃。

正确使用温度计
1：温度计的玻璃泡要全部浸没在液体中，不能碰到容器底或侧壁。
2：玻璃泡浸入被测液体要稍候一会儿，待示数稳定再读数。
3：读数时，温度计要继续留在被测液体中，视线要和刻度线相平。

三. 体温计：量程为35℃—42℃，分度值为0.1℃，所装液体为水银。
①结构特点：玻璃泡和直玻璃管之间有一段非常细的狭口。
②体温计能离开人体读数。
③使用前要甩一甩。
④泡大管细结构特点导致精确度高
体温计如果不甩的话：只升不降

四. 伽利略温度计的原理
核心原理：利用气体的热胀冷缩。
结构：一根细长玻璃管，一端封闭成球形（装空气），另一端开口插入盛水的容器中。
工作方式：
 温度升高 → 球内空气膨胀 → 管内水柱下降
温度降低 → 球内空气收缩 → 管内水柱上升
通过水柱高度变化定性判断温度高低（无精确刻度）
1. 原理： 液体的热胀冷缩
2. 分类：
液体：水银 煤油 酒精
用途： 实验室用温度计 寒暑表 体温计
