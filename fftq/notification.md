② 文中指通常沈阳中午气温30度，不排除特殊情况。
③ 删除后变成沈阳夏日中午气温一定是30度，过于绝对，不符原意。
④ 体现说明文语言准确严密。

## 2026年7月26日 10:13 Sunday

```
2. 眼睛的调节
看远处物体：远处光线为平行光 → 晶状体变薄，折光能力变弱。
看近处物体：近处光线会聚拢 → 晶状体变厚，折光能力变强。
3. 视物距离标准
1. 远点：眼睛能看清的最远距离，正常眼远点在无限远。
2. 近点：眼睛能看清的最近距离，约10cm。
3. 明视距离：看物体清晰且眼睛不易疲劳的距离，约25cm。

②近视眼
1. 症状：近处看得清晰，远处模糊。
2. 成因：
⑴晶状体太厚，折光能力过强；
⑵ 眼球前后方向过长。
3. 成像位置：物体的像成在视网膜前方
4. 矫正方式：佩戴凹透镜（发散光线，延后成像到视网膜上）
```

2. 睫状体：改变晶状体的厚薄，以此调整焦距。
