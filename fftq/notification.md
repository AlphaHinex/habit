```
句子成分总口诀
看全句，抓中心，缩句先找主谓宾
主干成分主谓宾，枝叶成分定状补。
定语必在主宾前。谓前为状谓后补。
状语有时位主前，逗号隔开心有数。

六大成分含义
1. 主语（谁/什么）：句子陈述的对象，动作发出者，多为名词、代词

2. 谓语（做什么/是什么）：主语的动作、状态，多为动词、形容词

3. 宾语：谓语动作的承受对象，名词、代词居多

4. 定语（……的）：修饰限定主语、宾语，放在主宾前面

5. 状语（……地）：修饰谓语，表时间、地点、方式、程度，多在谓语前，部分放句首

6. 补语（得……）：补充说明谓语，放在谓语后面

划分符号规范
主语：双横线 ＝
谓语：单横线 —
宾语：波浪线 ～
定语：小括号 ( )
状语：中括号 [ ]
补语：尖括号 < >

基础句式模板
1. (定语)主语 [状语] 谓语 <补语> (定语)宾语

2. 例句：(可爱的)小明 [开心地] 捡起 <起来> (红色的)皮球。

易错要点
1. “的”后多为主语、宾语，“地”后是谓语，“得”后是补语

2. 时间、地点放句首，整体算作句首状语，加逗号隔开

3. 缩句只保留主谓宾，删掉定状补所有修饰成分

议论文尾段作用

1. 总结全文

3. 突出强调中心论点；点明中心论点（如果中心论点在结尾第一次出现）
```

```
1. 平方根：正数有两个互为相反数的平方根，0的平方根是0，负数无平方根；算术平方根是非负的平方根
```

```
1.平均速度

平均速度是指在某段时间内，物体运动的路程与所用时间的比值，反映的是某段路程中物体运动的平均快慢。
用v表示平均速度，用s表示路程，用t表示时间，则平均速度的公式是：v = s/t

2.测量“小车平均速度”实验

（1）实验器材

小车、斜坡（长木板）、小木块、金属片挡板、刻度尺、停表（秒表）

（2）实验原理

v = s/t

（3）实验步骤

①选材，将所需要器材准备好，置于水平桌面；
```

```
运动的快慢
一、速度
物理学中采用“相同时间比较路程”的方法定义速度，即用运动的路程除以所用时间，代表单位时间内走过的路程。

1. 定义：路程与时间之比叫做速度。

2. 公式：v=s/t
变形公式：s=vt ，t=s/v
v代表速度，s代表路程，t代表时间

3. 单位
国际单位：米/秒，符号m/s或m·s⁻¹，读作：米每秒
常用单位：千米/小时，符号km/h，读作：千米每小时
单位换算：1m/s=3.6km/h ，1km/h=1/3.6 m/s
换算口诀：m/s换算km/h乘以3.6；km/h换算m/s除以3.6

4. 物理意义：表示物体运动快慢的物理量。速度越大，运动越快；速度越小，运动越慢。
数值含义：数值上等于物体1秒内通过的路程，例：20m/s表示物体每秒通过的路程为20米。

二、机械运动分类

按照运动路线曲直分为直线运动、曲线运动；
直线运动按照速度是否变化分为匀速直线运动、变速直线运动。

1. 匀速直线运动：沿着直线且速度不变的运动，是最简单的机械运动。

2. 变速直线运动：沿着直线且速度发生改变的运动
```

```
1. 定义

前往外国时，人产生困惑、陌生、焦虑的感受，这种体验叫做culture shock 文化冲击。
成因：不了解当地语言、本土文化，思念家人朋友。

2. 文化适应四阶段

1. Honeymoon Phase 蜜月阶段
抵达异国感到兴奋，一切新奇，乐于探索新文化。
2. Negotiation Phase 协商阶段

3. Adjustment Phase 调整阶段
慢慢应对困难，预判各类场景，接纳本土文化，学会处理不如意的事。
4. Adaptation Phase 适应阶段
在新文化中找到归属感，文化差异不再构成难题。

3. 拓展概念

reverse culture shock 逆向文化冲击
```

```
共含有2个未知数的两个一次方程组成的一组方程。

2. 方程组的解
两个方程的公共解，数值必须同时满足组内所有方程；常规方程组只有唯一一组解，特殊情况存在无数组解。

三、代入消元法
1. 核心思路
消元，把二元方程组转化为一元一次方程求解。

2. 方法定义

1. 判断一组数是否为方程的解：将x、y代入等式，左右两边相等即为解。
2. 已知方程的一组解，求参数：把解代入原式，得到含参数的一元一次方程，计算参数值。
```

```
📚英语
一、基本结构
肯定句

主语 + have / has + 动词过去分词
I/You/We/They + have done
He/She/It + has done

否定句

主语 + have/has + not + 过去分词
haven’t = have not；hasn’t = has not

一般疑问句

Have / Has + 主语 + 过去分词？
回答：Yes, 主语+have/has. / No, 主语+haven’t/hasn’t.

二、两种核心用法

1. 过去发生，对现在造成影响（无明确过去时间）
标志词：already, yet, just, ever, never
例：I have finished my homework.（现在作业写完了，可以出去玩）

2. 动作从过去持续到现在
标志词：for + 时间段；since + 时间点/过去句子
动词必须用延续性动词
例：I have lived here for 5 years.

三、常考标志词

1. already 已经（肯定句，句中/句末）

2. yet 还、已经（否定句句末）

3. just 刚刚；ever 曾经；never 从不

4. before 以前；recently 最近

5. for + 时长；since + 过去时间

四、重点难点：短暂性动词 ↔ 延续性动词（必考）

短暂动词不能和for/since连用，要转换：

1. buy → have

2. borrow → keep

3. die → be dead

4. leave → be away

5. join → be in/be a member of

6. begin/start → be on

7. finish → be over

8. arrive/reach/get to → be in/at

例：He left 3 days ago.
= He has been away for 3 days.

五、have been to / have gone to / have been in 区分

1. have been to + 地点：去过某地（现在已回来）

2. have gone to + 地点：去了某地（人还没回来，不在现场）

3. have been in + 地点 + 时长：待在某地多久

六、易错点

1. 不能和yesterday, last week, just now等过去时间词连用（搭配一般过去时）

2. since后句子用一般过去时，主句现在完成时
```

```
📚数学
直线y=kx+b可以看作是直线y=kx上下平移得到 b>0时向上平移b个单位 b<0时 向下平移|b|

 一次函数基础表达式
1. 通用形式：y=kx+b (k≠0)
2. 特殊：b=0时，y=kx，为正比例函数
3. 判定条件
① x的系数k≠0；
② x的次数为1；
4. 字母含义
k：斜率（一次项系数，式子要先合并同类项再判断）
b：截距（常数项）

二.k的正负（增减性）
k>0时，从左向右看图象呈上升趋势，y随x的增大而增大；
k<0时，从左向右看图象呈下降趋势，y随x的增大而减小。

三、|k|的大小（倾斜程度）
|k|越大，直线越陡，直线与x轴的夹角（锐角）越大
|k|越小，直线越坡，直线与x轴的夹角（锐角）越小

四. b值的大小及正负
b——直线与y轴交点的纵坐标
b>0时，与y轴正半轴相交；b<0时，与y轴负半轴相交；b=0时，经过原点。

五、k值相同 ⇔ 两直线平行
k值互为负倒数（k_1·k_2=-1）⇔ 两直线垂直
```

```
📚英语
一、基本概念
1. 原级：描述本身，无对比
2. 比较级：两者对比，“更……”
3. 最高级：三者及以上对比，“最……”

二、规则变化
1. 直接加-er / -est
tall→taller→tallest
short→shorter→shortest
slow→slower→slowest

2. 以e结尾，只加-r / -st
nice→nicer→nicest
late→later→latest
fine→finer→finest

3. 重读闭音节：辅+元+辅，双写末尾字母再加-er/-est
big→bigger→biggest
thin→thinner→thinnest
hot→hotter→hottest
red→redder→reddest

4. 辅音字母+y结尾：变y为i，再加-er/-est
happy→happier→happiest
easy→easier→easiest
busy→busier→busiest

5. 多音节词（3个音节及以上）/部分双音节词：前面加more / most
beautiful → more beautiful → most beautiful
interesting → more interesting → most interesting
carefully → more carefully → most carefully

三、不规则变化（必背）
good/well → better → best
bad/ill → worse → worst
many/much → more → most
little → less → least
far → farther/further → farthest/furthest

四、核心句型
（1）原级句型
1. as + 原级 + as  和……一样
He is as tall as me.

2. not as/so + 原级 + as  不如……
She is not so outgoing as her sister.

（2）比较级句型（两者比较）
1. A + be/动词 + 比较级 + than + B  A比B更……
Tom runs faster than Jack.

2. 比较级 + and + 比较级  越来越……
taller and taller 越来越高
more and more beautiful 越来越漂亮

3. the + 比较级，the + 比较级  越……，就越……
The more you read, the better you will be.

（3）最高级句型（三者/以上）
1. 主语 + be/动词 + the + 最高级 + 范围（in/of短语）
Lily is the thinnest in our class.

2. one of the + 最高级 + 复数名词  最……之一
Beijing is one of the biggest cities in China.

五、易错点
1. 最高级前面必须加the；副词最高级the可省略

2. than前后对比对象要一致，不能人和物对比

3. much/even/far 可修饰比较级（much taller 高得多）

4. 出现than只用比较级；in/of+群体用最高级
```

```
老师今天上课先给大家讲了昨天留的作业 接着大家练习了透镜的练习题 接着讲了温度计
温度
一、温度定义：表示物体的冷热程度，凭感觉判断温度不准

二、温度计：测量温度的工具。
①原理：常用温度计是根据液体的热胀冷缩的性质制成的。
液体包括：水银、煤油、酒精。
按用途分：实验室用温度计、寒暑表、体温计。

摄氏温度：温度计上的字母℃表示的是摄氏温度。
摄氏温度的规定：在一个标准大气压下冰水混合物的温度是0摄氏度，沸水的温度是100摄氏度，0℃和100℃之间分成100等份，每等份代表1℃。

正确使用温度计
1：温度计的玻璃泡要全部浸没在液体中，不能碰到容器底或侧壁。
2：玻璃泡浸入被测液体要稍候一会儿，待示数稳定再读数。
3：读数时，温度计要继续留在被测液体中，视线要和刻度线相平。

三. 体温计：量程为35℃—42℃，分度值为0.1℃，所装液体为水银。
①结构特点：玻璃泡和直玻璃管之间有一段非常细的狭口。
②体温计能离开人体读数。
③使用前要甩一甩。
④泡大管细结构特点导致精确度高
体温计如果不甩的话：只升不降

四. 伽利略温度计的原理
核心原理：利用气体的热胀冷缩。
结构：一根细长玻璃管，一端封闭成球形（装空气），另一端开口插入盛水的容器中。
工作方式：
 温度升高 → 球内空气膨胀 → 管内水柱下降
温度降低 → 球内空气收缩 → 管内水柱上升
通过水柱高度变化定性判断温度高低（无精确刻度）
1. 原理： 液体的热胀冷缩
2. 分类：
液体：水银 煤油 酒精
用途： 实验室用温度计 寒暑表 体温计

绝对零度（t）：-273.15℃   开尔文（T）
T=t+273.15K
```
