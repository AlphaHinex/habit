```
2026年7月12日 初二F班语文
第2节             助教：姜老师

📚 语文
句子成分
句子由词/短语+语气构成，共6种成分：
1. 基本成分：主语、谓语、宾语

2. 补充成分：定语（）、状语（）、补语〈〉

识别主语
1. 主语定义
执行动作、被陈述描述的对象。

2. 可充当主语的成分
名词：太阳升起来了。
代词：他参加活动。
数量词：一天是二十四小时。
数词：零是实数。
偏正短语：在妈妈面前撒娇是一种幸福。
动宾短语：成为有用的人是愿望。
主谓短语：董卿主持好不好？
的字短语：出门遇到的是我同事。
动词：笑是有多重意义的语言。

3. 做题关键
找句子描述的核心对象，动作发出者/被说明主体。

识别谓语
1. 谓语定义
说明主语做什么、是什么、怎么样；常由动词、形容词充当，名词、短语也可作谓语。

2. 四类谓语
①动词作谓语（最常见）
表动作、行为、发展变化
例：老师笑了；工业发展了；太阳升起来；战士献青春。

②形容词作谓语
表主语状态、样貌
例：山谷寂静；春天脚步近了；小草青得逼眼。

③名词作谓语
仅限说明日期、节日、天气、外貌
例：今天星期五；十月一日国庆节；姑娘细高个儿，瓜子脸。

④短语作谓语（主谓/偏正/并列）
结构：大主语+短句
例：陈依龄成绩优秀；故宫雄伟壮观；我父亲江苏人。

3. 做题区分技巧
 动词谓语：有动作、变化；
形容词谓语：描写样貌、情绪、环境；
名词谓语：只用于时间、天气、长相；
短语谓语：一句话拆分两层主谓关系。
```

```
识别宾语
1. 宾语定义
谓语支配的对象，回答“谁”“什么”。
2. 可充当宾语的成分
①名词、代词
②动词、数量词、形容词、偏正短语、并列短语、主谓短语
3. 双宾语
一个动词后同时有人、物两个宾语。
例：老师告诉大家一个好消息。
4. 特殊规则
表心理的动词（记得、希望、觉得、感到、认为、证明、要求），后面短句/短语全部作宾语。

句子成分总口诀
看全句，抓中心，缩句先找主谓宾
主干成分主谓宾，枝叶成分定状补。
定语必在主宾前。谓前为状谓后补。
状语有时位主前，逗号隔开心有数。

识别定语
1. 定语定义
放在主语、宾语前面，修饰、限定名词；表归属、性质、数量、处所、时间等。
常用标志：“的”。

2. 定语两大分类
1）限制性定语：限定数量、时间、处所、归属、范围
例：（七月）的沈阳、（二斤）苹果、（我们班）的同学
2）描写性定语：描摹样貌、特征、用途
例：（紫红色）的大衣、（画画用）的笔

3. 能作定语的内容
动词、形容词、名词、代词、数量词、并列短语、偏正短语

4. 多层定语规则
主语、宾语前可叠加多个修饰词，即多层定语。
例：（一位六十多岁）的老大爷、（墙上挂着的一张）水彩画

先找句子主干（主谓宾）然后找定语
定语在主语宾语前面修饰主语和宾语

状语
1. 定义
放在谓语前面，修饰谓语，交代状态、程度、时间、处所、范围等；标志性字：地，划分标记[ ]。
2. 位置两类
① 谓语前（最常见）；② 句子最开头（主语前，表时间/评论/话题，逗号隔开）

补语
1. 定义
谓语后面的补充成分，回答“怎么样”，标志字：得，划分标记< >
```

```
1. 主语（谁/什么）：句子陈述的对象，动作发出者，多为名词、代词

2. 谓语（做什么/是什么）：主语的动作、状态，多为动词、形容词

3. 宾语：谓语动作的承受对象，名词、代词居多

4. 定语（……的）：修饰限定主语、宾语，放在主宾前面

5. 状语（……地）：修饰谓语，表时间、地点、方式、程度，多在谓语前，部分放句首

6. 补语（得……）：补充说明谓语，放在谓语后面

划分符号规范
主语：双横线 ＝
谓语：单横线 —
宾语：波浪线 ～
定语：小括号 ( )
状语：中括号 [ ]
补语：尖括号 < >

基础句式模板
1. (定语)主语 [状语] 谓语 <补语> (定语)宾语

2. 例句：(可爱的)小明 [开心地] 捡起 <起来> (红色的)皮球。

易错要点
1. “的”后多为主语、宾语，“地”后是谓语，“得”后是补语

2. 时间、地点放句首，整体算作句首状语，加逗号隔开

3. 缩句只保留主谓宾，删掉定状补所有修饰成分

议论文尾段作用

1. 总结全文

2. 论述了____（号召、提倡、鼓舞、强调+重要性）

3. 突出强调中心论点；点明中心论点（如果中心论点在结尾第一次出现）

4. 运用举例论证（道理论证、对比论证、比喻论证），有力证明中心论点

5. 补充论证中心论点，使论证更严密全面有力，深化中心论点
```
