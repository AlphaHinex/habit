```
平面直角坐标系
位置与坐标
一、确定位置
在平面内，确定一个物体的位置一般需要两个数据。

二、平面直角坐标系
1. 定义：在平面内，两条互相垂直且有公共原点的数轴组成平面直角坐标系。
水平轴：x轴或横轴，取向右为正方向；
铅直轴：y轴或纵轴，取向上为正方向；
x轴和y轴统称坐标轴，公共原点O为平面直角坐标系的原点。

2. 点的坐标
平面内任意一点P，向x、y轴作垂线，垂足对应数a（横坐标）、b（纵坐标），有序数对(a,b)是点P的坐标。
(1) 书写规则：横坐标在前，纵坐标在后，逗号隔开；
(2) 有序性：(a,b)与(b,a)顺序不同，代表不同点（a≠b时）；
(3) 一一对应：平面内点 ↔ 唯一有序实数对。

3. 点到坐标轴的距离
点P(x,y)：
到x轴距离：纵坐标绝对值 |y|
到y轴距离：横坐标绝对值 |x|

4. 特殊点的坐标
坐标轴上的点不属于任何象限。
(1) x轴上点：纵坐标为0；y轴上点：横坐标为0；
(2) 平行于x轴的直线：所有点纵坐标相同；平行于y轴的直线：所有点横坐标相同。

5. 各象限点坐标符号
第一象限P(a,b)：a>0，b>0
第二象限P(a,b)：a<0，b>0
第三象限P(a,b)：a<0，b<0
第四象限P(a,b)：a>0，b<0
```

```
一次函数 y=kx+b(k≠0)，图像是一条直线

k<0：直线从左上向右下倾斜，y随x增大而减小；
b>0：直线与y轴交于正半轴；
b<0：直线与y轴交于负半轴；
b=0：函数为正比例函数，图像过原点。
```
